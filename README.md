# Calendar App

A modern calendar and reminder application built with **React, TypeScript, Vite, and Tailwind CSS**.

## ✨ Features

* 📅 Calendar and event management
* ⏰ Create and manage reminders
* 🌐 **Persian and English** language support
* 🎨 Light and dark mode
* ⚙️ Customizable settings
* 🔔 Notification management
* 🗓️ Choose the first day of the week
* 💾 Data backup
* ♻️ Restore data from backup files
* 🗑️ Delete all data
* 🔐 Privacy and data management
* 📱 Responsive user interface
* 🧭 Home, Calendar, My Schedule, and Settings sections

## 🛠️ Technologies

* React
* TypeScript
* Vite
* Tailwind CSS
* Redux Toolkit
* React Router
* i18next
* React i18next
* date-fns-jalali
* Framer Motion

## 🚀 Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

To run the JSON Server:

```bash
npm run server
```
